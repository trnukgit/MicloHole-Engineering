# MORPHO - 微細穴加工による視覚効果デザインツール

## サイトについて

MORPHOは、微細穴加工（マイクロパーフォレーション）による角度依存の視覚効果をデザイン・シミュレーションするためのツールサイトです。

小さな穴を規則的に配置することで、見る角度によって文字や図形が浮かび上がったり、背景の透過度が変化したりする効果を生み出すことができます。

---

## ツールの使い方

### Signage Simulation（サインシミュレーション）

看板やサインの見え方をシミュレーションするツールです。

**主な機能：**
- 文字入力とパラメータ設定（厚み、穴径、観察距離など）
- 正面からの見え方をリアルタイムプレビュー
- Top View / Side View で可視範囲を確認
- Visible Range モードで各文字の可視範囲を円で表示
- 円をクリックして色を変更可能

**操作方法：**
- View Mode切替：Field（グラデーション表示）/ Visible Range（線画表示）
- マウスホイール：ズームイン・アウト
- ドラッグ：表示位置を移動
- ダブルクリック：ズーム・位置をリセット

---

### Parameter Optimization（パラメータ最適化）

目標とする視覚効果を実現するための最適な穴パラメータを探索するツールです。

**Auto モード：**
1. 素材の色（透明/不透明）を選択
2. 見せたいもの（文字・図形 / 背景変化）を選択
3. パラメータの探索範囲を設定
4. 目標角度や優先度を指定
5. 「計算開始」で最適なパラメータ候補を表示
6. 候補をクリックするとManualモードに適用

**Manual モード：**
- 加工範囲（幅・高さ）をスライダーで調整
- 穴パラメータ（厚み・穴径・間隔）を調整
- 2D View / 3D View でリアルタイムプレビュー
- 穴の総数や推定角度を確認
